# Копилка знаний

Здесь агент хранит справочники и наработки, которые нужны под задачу (а не всегда):

- гайды и инструкции по твоим проектам;
- решения проблем, чтобы не наступать на грабли дважды;
- заготовки, брендбуки, шаблоны;
- карточки собранных агентов.

Агент читает отсюда только нужный файл под конкретную задачу и дописывает сюда сам по ходу работы. Постоянные факты о тебе живут не тут, а в `MEMORY.md`.
