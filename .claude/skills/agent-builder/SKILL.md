# Конструктор агентов 🤖

Ты собираешь нового агента (нейросотрудника) под конкретную задачу владельца — по образу этого дома. Не лепи «на глаз»: сначала пойми задачу, потом собери минимально нужный комплект.

## Шаг 1. Пойми задачу

Коротко уточни (можно через скилл `discovery-interview`, если задача размытая):
- Что агент должен делать? Одна главная задача.
- Кому служит и в каком формате общается (Telegram, локально, голосом)?
- Какие инструменты нужны (код, дизайн, веб-поиск, работа с файлами, API)?
- Уровень автономности: осторожный / стандартный / автономный?
- Имя агента и короткое имя папки (latin, kebab-case).

Покажи короткий бриф своими словами и дождись «да».

## Шаг 2. Спроектируй комплект

Определи минимальный набор:
- **Персона** (`SOUL.md`) — характер, тон, принципы под роль.
- **Правила** (`CLAUDE.md`) — кто он, что читает при старте, память, светофор автономности, таблица скиллов.
- **Скиллы** — только те, что нужны под задачу. Не тащи лишнее. Можно скопировать из склада этого дома (`~/projects/agent-zavod/skills/`) или из рабочего стола.
- **Память** — `USER.md`, `MEMORY.md` (можно с плейсхолдерами под знакомство нового владельца).

## Шаг 3. Собери в отдельной папке

Создай `~/projects/<имя>/` и наполни ИНКРЕМЕНТАЛЬНО (по файлу):

```
~/projects/<имя>/
  CLAUDE.md            # правила + память + светофор
  SOUL.md              # характер под роль
  USER.md              # профиль (плейсхолдеры)
  MEMORY.md            # постоянная память
  README.md            # что это и как запустить
  memory/.gitkeep
  knowledge/README.md
  .claude/
    settings.json      # светофор разрешений (взять как в этом доме)
    skills/<нужные>/SKILL.md
```

## Схема файла скилла (чтобы генерённое совпадало с форматом)

Каждый скилл — `.claude/skills/<имя>/SKILL.md` с frontmatter:

```yaml
---
name: <имя-латиницей>
description: <что делает + КОГДА срабатывать; первое предложение = ключевой триггер>
user-invocable: true
# опционально: allowed-tools, model, disable-model-invocation (для деструктивных)
---
```

Тело скилла — инструкция агенту: шаги, правила, примеры. Роль-переключение (dev/design/research) делается через `description` скиллов, а не отдельными SOUL-файлами.

## Шаг 4. Отдай готовым и объясни

- Скажи простыми словами, что за агент получился и что умеет.
- Как запустить: «открой папку `~/projects/<имя>/` в Claude Code и напиши привет».
- Запиши карточку нового агента в `knowledge/` этого дома и строку в раздел «Собранные агенты» в `MEMORY.md`.

## Правила

- Инкрементально + коммит после каждого рабочего файла. Не переписывай большой файл целиком.
- Файл `SKILL.md` система защищает: пиши его через промежуточный файл и переноси (`mv`), либо через shell.
- Минимализм: лишний скилл в новом агенте только мешает. Меньше — лучше.
