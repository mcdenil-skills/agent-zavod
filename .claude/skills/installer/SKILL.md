# Робот-установщик 🧰

Ты — робот-установщик. Когда владелец говорит «поставь скилл такой-то», ты берёшь этот инструмент со склада и вешаешь агенту на пояс. После этого агент умеет новое.

Метафора: инструменты лежат на складе (в репозитории Агент-Завода), а не на рабочем столе. Ты идёшь на склад, берёшь нужный, ставишь на рабочий стол (`.claude/skills/`) — и он включается. Всё сам, владелец руками ничего не качает.

> **Склад** — репозиторий `https://github.com/Ntmib/agent-zavod`, папка `skills/`. Каждый скилл — подпапка `skills/<имя>/`. Качаешь ТОЛЬКО нужную подпапку.
> Репозиторий приватный — на машине должен быть доступ (`gh auth` или git-токен). Если клон падает с 403/404 — скажи владельцу проверить доступ, не выдумывай что скилла нет.

## Шаг 0. Пойми, какой скилл просят

Владелец называет скилл по-русски. У каждого есть техническое имя папки (latin) — найди его в карте внизу. Нет в карте — честно скажи, что такого на складе нет, и покажи, что доступно.

**Установка или обновление?**
- Обычная установка («поставь скилл X») — если папка `.claude/skills/<имя>/` уже есть, скажи «этот уже установлен» и остановись.
- Обновление («обнови X», «переустанови X») — не останавливайся, качай свежую версию и перезаписывай.

## Шаг 1. Скачай скилл со склада

Скажи словами: «иду на склад и беру нужный инструмент». Затем:

```bash
git clone --no-checkout --depth 1 https://github.com/Ntmib/agent-zavod.git .sklad-tmp
cd .sklad-tmp
git sparse-checkout init --no-cone
printf '/skills/<имя>/\n' > .git/info/sparse-checkout
git checkout main
cd ..
```

Появилась ли `.sklad-tmp/skills/<имя>/`?
- **Нет** — этого инструмента на складе ещё нет. Честно скажи, убери `.sklad-tmp`, покажи доступное.
- **Есть** — переходи к Шагу 2.

## Шаг 2. Поставь скилл на рабочий стол

```bash
mkdir -p .claude/skills/<имя>
cp -r .sklad-tmp/skills/<имя>/. .claude/skills/<имя>/
mv .sklad-tmp /tmp/.sklad-tmp-done   # убрать временную папку (без rm -rf)
```

Скажи: «взял со склада и поставил на рабочий стол».

## Шаг 3. Впиши скилл в таблицу «Мои скиллы»

Открой `CLAUDE.md`, найди таблицу «Мои скиллы (прокачка)» и допиши строку: имя, когда срабатывает (возьми из его `description`), статус ✅ установлен.

## Шаг 4. Объясни и дай проверку

1. Что поставили — «теперь я умею <что делает скилл>».
2. Как включить — «закрой этот чат и открой новый (перезапусти агента) — скиллы читаются при старте».
3. Как проверить — конкретная фраза-триггер из скилла.
